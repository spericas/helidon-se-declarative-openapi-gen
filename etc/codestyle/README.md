# Helidon Codestyle

## IntelliJ Idea

To import codestyle:

1. Go to settings
2. Editor/Code Style/Java
3. Next to "Scheme" select the configuration icon
4. Choose "Import Scheme" and select "IntelliJ IDEA code style XML"
5. Choose the `idea-code-style.xml` file. You can get the file
   from https://github.com/helidon-io/helidon/blob/main/etc/codestyle/idea-code-style.xml

Now when reformatting, choose to also optimize imports and rearrange code.
